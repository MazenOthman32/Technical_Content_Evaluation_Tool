# Instant+ Web (Next.js)

Root Directory على Vercel يجب أن يكون `web`.

## تشغيل محلي

من جذر المشروع (موصى به):

```powershell
..\scripts\dev.ps1
```

أو من داخل `web`:

```powershell
copy .env.local.example .env.local
npm install
npm run dev
```

ثم افتح: http://127.0.0.1:3000

راجع `../README.md` للتفاصيل الكاملة (Supabase، المعالج، PDF، التصنيفات).
